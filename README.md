# UI Kit опросов СКОЛКИ и ВДЕЛЕ

Интерактивный проект оформления для согласования и передачи разработчику. Три темы: СКОЛКА — светлая, СКОЛКА — тёмная, ВДЕЛЕ.

## Что можно посмотреть

- Горизонтальные полосы и круговую диаграмму в форме кольца.
- Примеры с голосами, равными лидерами, длинными названиями и без ответов.
- Одиночный и множественный выбор участника, подтверждение отправки.
- Кнопки, поля, переключатели, сообщения и фокус клавиатуры.
- Палитру с проверкой контраста и экспортом цветов в JSON.

## Публикация

Статический сайт без сервера и сборки. В GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.

Все ресурсы лежат рядом с `index.html`. Можно запустить локально через `python3 -m http.server 8000` и открыть адрес сервера.

## Границы прототипа

- Голоса демонстрационные. Запросов к API опросов и подключения к рабочей админке нет.
- Новые темы и настройки сохраняются только в localStorage конкретного браузера. Это демонстрация сценария, а не серверная библиотека тем.
- Сохранение и публикация в примере редактора не изменяют реальные опросы.
- Светлая тема повторяет палитру исходной системы. Некоторые светлые серии требуют отдельного решения по контрасту. Доступность не заявляется как полностью проверенная.
- Тёмная СКОЛКА и ВДЕЛЕ — предлагаемые адаптации. Финальные значения и состояния требуют согласования.
- Логотип ВДЕЛЕ взят из SVG сайта vdeleconf.ru (Asset_75-1.svg), заливка адаптирована под тёмный фон. Фирменный акцент #E6FD00 сверен с CSS сайта; окончание градиента #ECFD63 — адаптация для UI Kit.
- Редактор тем скрыт в версии v0.2; старые ссылки на него открывают диаграммы.

## Основа оформления

Типографика Gogh и логотип СКОЛКИ — из публичных ресурсов предоставленных пользователем сайтов. Геометрия и параметры диаграмм сверены с существующим компонентом опросов: градиентные заливки, белые полупрозрачные обводки, скругления и тени. Кольцевая диаграмма отрисована в ECharts 5.6.0 (Apache-2.0); уведомление о лицензии сохранено в файле библиотеки. Материалы брендов не предоставляются как самостоятельная библиотека для стороннего использования.

Дата подготовки: 30 октября 2026 года.

## Версия 0.3
Убраны служебные подписи, нижняя строка, подзаголовки тем и выбор примеров. Логотип СКОЛКИ без подписи: одна исходная картинка, в тёмной теме белая CSS-версия.
Для СКОЛКИ 10 фиксированных цветов: исходные 6 + 4 предлагаемых. Цвет категории сохраняется при сортировке; после 10 — нейтральный серый и рекомендации использовать полосы. Во ВДЕЛЕ любое число категорий: жёлтый максимум, остальные серые, при равенстве выделяются все максимумы. Проверочный пример: `?theme=dark&view=diagrams&type=bars&categories=10`.
